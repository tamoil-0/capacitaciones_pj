Fundamentos y Formulación General

Contexto de Aplicación

Las pruebas de hipótesis para proporciones se utilizan cuando la variable de interés es Cualitativa (Categórica) y dicotómica (solo dos resultados posibles: Éxito/Fracaso, Sí/No, Defectuoso/Conforme).

Diferencia clave con variables Cuantitativas:
  • Cuantitativo: Se analiza la media (μ) o la varianza (σ²). Ejemplo: Tiempo promedio de respuesta (segundos).
  • Cualitativo (Este caso): Se analiza la frecuencia relativa (π). Ejemplo: Porcentaje de servidores disponibles (%).
Supuestos del Modelo:
  • Muestreo aleatorio simple.
  • Independencia de observaciones.
  • Tamaño de muestra grande: nπ ≥ 5 y n(1-π) ≥ 5 para aproximar a la Normal.

El Estadístico de Prueba Z

Para muestras grandes, utilizamos la aproximación a la distribución normal estandarizada.

Zc = p-π0 π0(1-π0) n
NUMERADOR (p - π0):
Mide la distancia absoluta entre la evidencia muestral (p) y el valor hipotético poblacional (π0).
DENOMINADOR (Error Estándar):
Representa la variabilidad esperada de las proporciones muestrales. Actúa como un factor de escala para estandarizar la diferencia.
RESULTADO (Zc):
Número de desviaciones estándar que la muestra se aleja de la hipótesis nula.

4.1. Prueba de Cola Inferior (Unilateral Izquierda)

Definición Detallada

Se utiliza cuando el investigador desea demostrar que la proporción poblacional real (π) ha disminuido o es menor que un valor de referencia histórico o estándar (π0).

Planteamiento de Hipótesis:
  • H0: π ≥ π0 (Hipótesis Nula). Asume que la proporción se mantiene igual o es mayor.
  • H1: π < π0 (Hipótesis Alterna). Lo que queremos probar (disminución).
REGIÓN DE RECHAZO: Se ubica en el extremo izquierdo de la curva normal. Rechazamos H0 si el estadístico calculado Zc es menor que el valor crítico negativo -Zα.
Zc<-Zα

Representación Gráfica

La zona roja representa la región de rechazo (α). Si Zc cae aquí, la disminución es significativa.

Ejemplo de lógica:
Si esperamos un 90% de satisfacción (π0=0.9) y obtenemos una muestra con 60% (p=0.6), la diferencia es negativa. Si esa diferencia es lo suficientemente grande (supera el valor crítico), concluimos que la satisfacción bajó realmente.

Ejemplo 4.1: Conectividad en Ancón

Problema: OSIPTEL reporta que el 87.7% de hogares peruanos tienen internet. Se cree que en el distrito de Ancón la conectividad es menor. Se toma una muestra de 350 hogares, encontrando 243 con internet. Use α = 0.05.
PASO 1: DATOS Y PARÁMETROS
  • Muestra (n) = 350
  • Éxitos (x) = 243
  • Proporción Hipotética (π0) = 0.877
  • Nivel de Confianza = 95% (α=0.05)
  • Valor Crítico (Zα) = -1.645 (Cola Izq)
PASO 2: CÁLCULO DE PROPORCIÓN MUESTRAL p=xn=243350=0.6943
PASO 3: ESTADÍSTICO DE PRUEBA
Sustitución en fórmula Z: Zc = 0.6943-0.8770.877(1-0.877)350
Operación: Zc=-0.18270.01755=-10.41
PASO 4: CONCLUSIÓN

Como -10.41 < -1.645, el valor cae profundamente en la región de rechazo. Se rechaza H0. Existe evidencia significativa de que la conectividad en Ancón es menor al promedio nacional.

4.2. Prueba de Cola Superior (Unilateral Derecha)

Definición Detallada

Se utiliza cuando el objetivo es demostrar que la proporción poblacional ha aumentado o es mayor que el estándar establecido. Es común en pruebas de mejora de calidad o efectividad de ventas.

Planteamiento de Hipótesis:
  • H0: π ≤ π0 (Nula). Asume que no hubo mejora.
  • H1: π > π0 (Alterna). Lo que queremos probar (aumento).
REGIÓN DE RECHAZO: Se ubica en el extremo derecho. Rechazamos H0 si el estadístico calculado Zc es mayor que el valor crítico positivo +Zα.
Zc>Zα

Representación Gráfica

La zona verde representa la región de rechazo (α). Valores altos de Z confirman el aumento.

Ejemplo de lógica:
Si implementamos una mejora para subir la eficiencia del 90% (π0=0.9) y la muestra arroja 95% (p=0.95), necesitamos que esta diferencia positiva sea estadísticamente sólida (Z alto) para descartar que fue suerte.

Ejemplo 4.2: Disponibilidad de Servidores

Problema: El SLA garantiza 99.0% de disponibilidad. Se instala un nuevo algoritmo y en 1000 peticiones, 996 son exitosas. ¿Ha mejorado significativamente la disponibilidad?
PASO 1: DATOS Y PARÁMETROS
  • Muestra (n) = 1000
  • Éxitos (x) = 996
  • Meta (π0) = 0.99
  • Nivel de Confianza = 95% (α=0.05)
  • Valor Crítico (Zα) = +1.645 (Cola Der)
PASO 2: CÁLCULO DE PROPORCIÓN MUESTRAL p=9961000=0.996
PASO 3: ESTADÍSTICO DE PRUEBA
Error Estándar (Denominador): 0.99(0.01)1000 = 0.0000099 = 0.00315
Cálculo Final Z: Zc = 0.996-0.990.00315 = 1.90
PASO 4: CONCLUSIÓN

Como 1.90 > 1.645, rechazamos H0. El nuevo algoritmo ha mejorado significativamente la disponibilidad del sistema.

4.3. Prueba Bilateral (Dos Colas)

Definición Detallada

Se utiliza para detectar cualquier cambio significativo, ya sea un aumento o una disminución respecto al parámetro. Es la prueba más rigurosa y conservadora.

Planteamiento de Hipótesis:
  • H0: π = π0 (Nula). Asume igualdad exacta.
  • H1: π ≠ π0 (Alterna). Probar diferencia (≠).
REGIÓN DE RECHAZO DIVIDIDA: El riesgo α se divide en dos colas (α/2). Rechazamos si el valor cae muy a la izquierda O muy a la derecha.
|Zc|>Zα/2

Representación Gráfica

La región de rechazo son las dos colas amarillas. Ambas suman α.

Importancia del Valor Absoluto |Zc|:
En esta prueba, no nos importa el signo (si subió o bajó), solo la magnitud del cambio. Tomamos el valor absoluto del Z calculado y lo comparamos con el crítico positivo (ej: 1.96). Si la magnitud es mayor, es significativo.

Ejemplo 4.3: Streaming en Lima

Problema: Históricamente el 49% usa streaming. En una muestra reciente de 540 personas, 283 lo usan. ¿Ha cambiado el uso (ya sea subido o bajado)?
PASO 1: DATOS Y PARÁMETROS
  • Muestra (n) = 540
  • Éxitos (x) = 283
  • Histórico (π0) = 0.49
  • Confianza = 95% (α=0.05, α/2=0.025)
  • Valor Crítico (Zα/2) = 1.96
PASO 2: CÁLCULO DE PROPORCIÓN MUESTRAL p=283540=0.5241
PASO 3: ESTADÍSTICO DE PRUEBA
Error Estándar: 0.49(0.51)540 = 0.0215
Calculo Z: Zc = 0.5241-0.490.0215 = 1.58
PASO 4: CONCLUSIÓN

Tomamos el valor absoluto |1.58| = 1.58. Como 1.58 < 1.96, NO se rechaza H0. Aunque subió al 52%, la diferencia no es estadísticamente significativa para afirmar un cambio poblacional.

4.4. Prueba de Diferencia de Proporciones

Comparación de Dos Poblaciones Independientes

Se utiliza para determinar si existen diferencias significativas entre dos grupos distintos (Ej: Hombres vs Mujeres, Grupo A vs Grupo B, Algoritmo 1 vs Algoritmo 2).

Zc = p1-p2 p(1-p)(1n1+1n2)
NUMERADOR: Diferencia real observada entre las dos muestras.
DENOMINADOR: Error estándar combinado para la diferencia de dos variables aleatorias independientes.

La Proporción Ponderada (p)

Bajo la hipótesis nula (H0: π1 = π2), asumimos que ambos grupos provienen de la misma población en cuanto a esa característica.

p=x1+x2n1+n2
¿POR QUÉ SE PONDERA?
Para obtener una estimación más precisa de la varianza, combinamos los éxitos totales y los dividimos por el total de observaciones (n1 + n2). Esto crea un "promedio pesado" que estabiliza el cálculo del error estándar.

Ejemplo 4.4: A/B Testing (Algoritmos)

Problema: Comparar la tasa de conversión. El Algoritmo A tuvo 15% de éxito y el B 20%. Ambos con muestra de 1000. ¿Es B realmente mejor o fue azar? (Prueba Bilateral para detectar diferencia).
PASO 1: DATOS
  • Muestra A: n1=1000, p1=0.15 (x1=150)
  • Muestra B: n2=1000, p2=0.20 (x2=200)
  • Confianza: 95% (Zcrit = 1.96)
PASO 2: PROPORCIÓN PONDERADA p=150+2002000=3502000=0.175
PASO 3: ESTADÍSTICO Z
Error Estándar (Usando p=0.175): 0.175(0.825)(11000+11000) = 0.017
Cálculo Z: Zc = 0.15-0.200.017 = -0.050.017 = -2.94
PASO 4: CONCLUSIÓN

|-2.94| = 2.94. Como 2.94 > 1.96, rechazamos H0. Existe una diferencia significativa: el Algoritmo B es superior.
